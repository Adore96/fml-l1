# Next-90-Day Purchase Prediction (Online Retail)

Predict whether a customer will make a purchase within 90 days using the UCI Online Retail dataset.

## Dataset Overview

The UCI Online Retail dataset contains transactional data of a UK-based online retail store. It includes information about customer purchases, including product details, quantity, price, and customer demographics. The dataset is suitable for building predictive models to forecast customer behavior and identify potential churn.
